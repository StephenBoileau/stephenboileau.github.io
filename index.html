Paladin Auto-Rig — One-Click Character Rigging for Maya & Blender (2026)

A one-click auto-rig tool, written in Python, that turns a character mesh on a Mixamo-style skeleton — including Meshy AI characters — into a fully rigged, animation-ready, game-exportable asset in under a minute. Built for Maya and ported to Blender.

Builds a complete production rig automatically: FK/IK arms and legs with stretch, reverse-foot, finger and thumb curl controls, forearm twist joints, and skinning. Imports Mixamo and mocap animation with additive cleanup, and exports game-ready FBX. A drag-and-drop installer creates the Maya shelf button, so there's no script editing to get started. Rigging that took hours by hand now takes seconds.

Tools: Python, PyMEL, Maya, Blender, rigging, skinning, FK/IK, mocap import, FBX export.

NightFlight Expedition – Dollywood (2026) — Coming Soon!

Technical Artist and Developer at Super 78 on media production for NightFlight Expedition, Dollywood's landmark indoor attraction — the world's first indoor family hybrid coaster and whitewater river raft ride, blending coaster, raft, and boat sequences with immersive projected media.

Built the Unreal Engine rendering pipeline for large-format output at non-standard render dimensions, producing high-resolution media for the attraction's projection systems. Wrote the Python automation around Movie Render Queue that runs 1–8 renders a night unattended, converts the raw output to VR-viewable review media, renames it to the project convention, files it in dated folders on the server, and posts Slack alerts on completion and failure — so the editor and clients could review on a headset before anything was cut into the show.

Owned environment optimization and performance: LODs and HLODs, draw-call, texture, and material reduction, shadow and lighting optimization, occlusion culling and asset streaming, and GPU/CPU/memory profiling to find and fix bottlenecks. Stood up and administer the production's Perforce server on Linux in Google Cloud for 4–5 external vendors plus the internal team.

The attraction is currently in a phased opening, so only officially released preview media is shown here. Super 78 is featured in Dollywood's official making-of series below.

Tools: Unreal Engine 5, Movie Render Queue, Python render automation, large-format rendering, custom render dimensions, Blueprints, LODs/HLODs, profiling, material creation and editing, Slack notifications, Perforce, P4 server administration, Linux, Google Cloud.

Moxie Robot – Real-Time Character System (2020)

Worked at Embodied Inc. as a Technical Artist helping bring the Moxie robot to market, which launched in April 2020. Moxie is a social robot designed to support child development through expressive real-time character animation and interactive experiences.

Built the audio pipeline tool the design team used to ship sound without an engineering PR: a Python/PyQt GUI where a designer picks approved audio and its target Unity asset bundle, and the tool files it correctly and normalizes loudness against the existing sounds. The same tool scanned the JSON conversation markup to map which audio was used where and built Unity asset bundles from that, so the robot streamed only what an upcoming module needed on its low-end hardware.

Also wrote the Maya Python script that stripped rigs out of hundreds of animation files to keep them small enough for the device, built custom FBX exporters used on every animation export, and contributed character rigging, facial and blend-shape animation prep, C# development, and mobile graphics optimization.

Tools: C#, Python, PyQt, Maya, Unity, asset bundles, JSON, rigging, blendshapes, FBX export automation, mobile graphics optimization.
