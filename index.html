02 / MORE WORK

Moxie robot

Professional work · Embodied · 2020

Built designer-facing Python/PyQt audio and asset-bundle tools; automated Maya animation preparation and standardized FBX export. Helped ship the real-time character on embedded hardware.

More info

Worked at Embodied Inc. as a Technical Artist helping bring the Moxie robot to market, which launched in April 2020. Moxie is a social robot designed to support child development through expressive real-time character animation and interactive experiences.

Built the audio pipeline tool the design team used to ship sound without an engineering PR: a Python/PyQt GUI where a designer picks approved audio and its target Unity asset bundle, and the tool files it correctly and normalizes loudness against the existing sounds. The same tool scanned the JSON conversation markup to map which audio was used where and built Unity asset bundles from that, so the robot streamed only what an upcoming module needed on its low-end hardware.

Also wrote the Maya Python script that stripped rigs out of hundreds of animation files to keep them small enough for the device, built custom FBX exporters used on every animation export, and contributed character rigging, facial and blend-shape animation prep, C# development, and mobile graphics optimization.

Tools: C#, Python, PyQt, Maya, Unity, asset bundles, JSON, rigging, blendshapes, FBX export automation, mobile graphics optimization.
